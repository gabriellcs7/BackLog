# Grand Theft Auto

Catálogo reduzido aos jogos principais, conforme solicitado pelo usuário. Spin-offs, expansões, jogos de celular e versões duplicadas foram retirados. Os IDs dos jogos mantidos e seus status permanecem iguais.

## Referências

- https://www.rockstargames.com/games
- https://www.grandtheftwiki.com/Games
- https://en.wikipedia.org/wiki/Grand_Theft_Auto

## Jogos adicionados

- **Grand Theft Auto** (1997)
- **Grand Theft Auto 2** (1999)
- **Grand Theft Auto III** (2001)
- **Grand Theft Auto: Vice City** (2002)
- **Grand Theft Auto: San Andreas** (2004)
- **Grand Theft Auto IV** (2008)
